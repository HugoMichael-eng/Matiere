We are NOT redesigning MATIÈRE from scratch.

Keep the current navigation, product architecture, typography direction and overall brand language.

This pass is specifically about fixing the current visual problem:

**The product is too uniformly dark, too flat, too repetitive, and too visually similar from screen to screen.**

MATIÈRE needs stronger environmental contrast, richer composition and clearer differences between creative spaces and technical spaces.

The new visual principle is:

# GALLERY → STUDIO → LABORATORY

The application should feel like moving through three related environments.

---

# 1. CREATE THREE VISUAL MODES

Do not use the same black background on every page.

## MODE A — ATMOSPHERE

Used for:

- Studio hero
- project introductions
- Inspiration / Moodboard
- Focus Mode
- large visual moments

Visual characteristics:

- deep black / charcoal
- large-scale imagery
- cinematic compositions
- minimal UI
- expressive typography
- strong contrast
- user imagery provides color

This is where MATIÈRE feels immersive.

---

## MODE B — STUDIO

Used for:

- Project Overview
- Notes
- Evaluation
- general creative development
- project research

Visual characteristics:

- warm bone
- soft off-white
- pale mineral grey
- black / charcoal typography
- editorial spacing
- tactile feeling
- thin subtle rules
- imagery integrated with content

This should feel like a working creative studio or beautifully designed notebook.

---

## MODE C — LAB

Used for:

- Formula Library
- Formula Editor
- Formula Comparison
- technical material information
- IFRA / dosage / calculations

Visual characteristics:

- pale neutral background
- tighter information density
- stronger grid
- precise typography
- technical mono type where useful
- high contrast
- minimal decorative imagery

This should feel like a precise workbench.

Do NOT make it sterile.

It should still feel distinctly MATIÈRE.

---

# 2. GLOBAL COLOR CORRECTION

The current interface uses:

black background  
bronze/brown rules  
cream typography

almost everywhere.

This is becoming monotonous.

Keep deep black as an important brand color, but do NOT use it as the default surface for every screen.

Create contrast between:

BLACK / CHARCOAL  
WARM BONE  
OFF-WHITE  
PALE GREY

Use warm bronze/brown very sparingly.

Do not outline every component in brown.

Do not make every divider brown.

Use mostly neutral hairline rules.

The user’s images and project references should provide most of the color.

# 20. MOTION

Use restrained motion only.

Allow:

subtle image reveal  
soft fade  
small hover shift  
smooth content expansion  
gentle transitions between environments

Do NOT add flashy animation.

The most important immersive quality should come from composition, imagery and continuity.

---

# 21. FINAL DESIGN GOAL

MATIÈRE should not feel like:

a black luxury SaaS dashboard.

It should feel like moving between:

# A GALLERY
where inspiration and atmosphere dominate

# A STUDIO
where ideas, notes, materials and evaluation live

# A LABORATORY
where formulas become precise and technical

All three spaces must still clearly belong to one MATIÈRE design system.

The interface provides structure.

The user’s fragrance work provides emotion.

Implement this art-direction correction across the current screens without changing the underlying navigation or core product architecture.
