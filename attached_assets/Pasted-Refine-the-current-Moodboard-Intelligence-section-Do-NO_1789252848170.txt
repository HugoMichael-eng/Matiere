Refine the current Moodboard Intelligence section.

Do NOT redesign the entire page.

The current implementation feels visually messy because too many elements are competing for attention:

- overlapping moodboard images
- three oversized interpretation names
- descriptive copy
- olfactive tags
- interpretation content

We need significantly more hierarchy and calm.

The design principle for this section is:

# ONE BOARD → ONE READING → ONE ACTIVE DIRECTION

The user should understand the process immediately.

Do not display all three interpretations as equally dominant visual objects.

---

# 1. CREATE A CLEAR THREE-PART COMPOSITION

On desktop use a controlled 12-column composition:

## LEFT — MOODBOARD
approximately 5 columns

## CENTER — MATIÈRE READING
approximately 2 columns

## RIGHT — ACTIVE DIRECTION
approximately 5 columns

The composition should feel balanced and editorial.

Do not use a hard vertical divider.

Use whitespace to separate the three areas.

# 2. SIMPLIFY THE MOODBOARD PREVIEW

The current moodboard preview contains too much overlap.

This explanatory page is NOT the full Canvas.

The actual Canvas can be freeform and expressive.

Here, show a curated preview.

Use only:

- one large anchor image
- one medium image
- one smaller overlapping image

Maximum 3 images visible at once.

Do not overlap them excessively.

Allow approximately 15–25% overlap, not 50%.

Make the composition feel like photographs placed carefully on a gallery table.

Use more negative space around them.

Example:

large fogged glass reference

medium warm skin reference slightly overlapping the right edge

small dark lacquer reference placed lower

Do not create a dense pile.

# 6. MOVE OTHER INTERPRETATIONS INTO A QUIET SWITCHER

Do NOT show:

and

show the short descriptor.

# 7. DIRECTION SWITCHING SHOULD FEEL ELEGANT

When the user changes:

SOFT FOCUS

to:

AFTER DARK

animate three things together:

1. relevant moodboard reference gains emphasis
2. MATIÈRE READING keywords change
3. active direction content transitions

Use a gentle 250–350ms transition.

Do not reload the section.

Do not move the entire layout.

The framework stays stable while the interpretation evolves.
