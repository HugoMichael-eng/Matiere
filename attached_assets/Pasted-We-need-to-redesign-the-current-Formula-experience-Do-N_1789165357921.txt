# CORE PRINCIPLE

The Formula workflow should feel like moving through a fragrance-development process, not clicking through nine database tabs.

The emotional progression should be:

**IMAGINE → BUILD → UNDERSTAND → TEST → REFINE → REALIZE**

Each stage should feel distinct.

Do NOT make all nine screens use the same layout.

---

# 1. STOP USING BLACK EVERYWHERE

The entire workflow should not remain on a black background.

Introduce environmental transitions.

Use three surface families:

## ATMOSPHERE
Deep charcoal / black  
Used for conceptual and immersive moments.

## WORKSPACE
Warm bone / parchment / soft grey  
Used for creative development.

## LAB
Pale mineral neutral  
Used for analytical and technical work.

Suggested stage mapping:

CONCEIVE → ATMOSPHERE

CREATE → WORKSPACE

FORMULATE → LAB

ANALYZE → LAB

CHECK → LAB

OPTIMIZE → WORKSPACE / LAB hybrid

DOCUMENT → WORKSPACE

SOURCE → WORKSPACE / LAB

MAKE → LAB

The transition between stages should be visible.

The user should feel that they are moving into a different mode of thinking.

---

# 2. FORMULA HEADER

Keep the formula identity persistent:

ANIMAL IN THE MIRROR

FORMULA 011 · V2

But reduce the amount of static header chrome.

Do not repeat unnecessary metadata everywhere.

Allow the project mood / inspiration to appear subtly in the header.

For example:

a faint cropped project image  
a texture from the moodboard  
a translucent visual fragment

Do not use decorative wallpaper.

Use real project content.

# 3. STAGE NAVIGATION

Keep the nine-stage workflow, but redesign the navigation.

Use:

- animate the active indicator
- transition the page surface
- gently fade / slide content
- preserve context

# 6. FORMULATE — TURN THIS INTO THE WORKBENCH

The Formula stage should be much lighter and more precise.

Use LAB mode.

Background:

soft warm grey / off-white.

This is where the user should feel maximum clarity.

Make the formula table the hero.

Columns:

MATERIAL  
%  
GRAMS  
DILUTION  
ROLE  
STATUS

Allow direct inline editing.

Use mono typography for numbers.

Add responsive micro-interactions:

- edited values softly highlight
- changed values briefly animate
- formula total updates live
- rows can reorder smoothly
- material search expands in place
- formula changes can be undone

Avoid putting each material inside its own giant dark card.

Use a clean continuous table / ledger.
