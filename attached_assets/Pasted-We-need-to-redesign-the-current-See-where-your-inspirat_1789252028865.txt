We need to redesign the current **“See where your inspiration could lead”** section.

Do NOT change the underlying product logic.

The current section works functionally, but visually it feels too flat, too software-like and too one-dimensional.

Right now the experience is:

moodboard on the left  
radio-button style suggested directions on the right  
text explanation underneath

This feels like a configuration panel.

MATIÈRE should instead make this moment feel like:

**a visual world transforming into scent.**

This is one of the most important moments in the entire product and it needs significantly more emotional, spatial and interactive impact.

---

# CORE IDEA

The user has created a visual world.

MATIÈRE should now reveal several possible olfactive interpretations of that world.

Do not present those interpretations as form options.

Present them as:

# THREE POSSIBLE WORLDS

Each direction should feel like a distinct creative interpretation.

The experience should communicate:

ONE MOODBOARD  
→  
MULTIPLE POSSIBLE SCENT WORLDS

---

# 1. REMOVE THE CURRENT 50 / 50 SOFTWARE SPLIT

The current rigid left / right division feels too administrative.

Replace it with a more fluid, asymmetric composition.

The moodboard should occupy approximately 55–65% of the visual space.

The interpretation layer can overlap, float beside, or partially enter the visual composition.

Avoid a visible hard vertical dividing line.

Use negative space, layering and typography instead.

The experience should feel spatial.

---

# 2. MAKE THE MOODBOARD FEEL PHYSICAL

The reference images should not look like three static rectangles.

Create more depth.

Use:

- overlapping imagery
- different object sizes
- slight depth
- visual stacking
- intentional negative space
- occasional image crop beyond expected boundaries

Do not make the collage chaotic.

Think contemporary exhibition installation / art direction wall.

On hover:

image lifts very slightly  
scale changes approximately 1–2%  
related references subtly respond

On click:

allow Focus Mode.

---

# 3. REPLACE “SUGGESTED DIRECTIONS” LIST

Do not show the three scent directions as radio-button rows.

This currently feels like filling out a form.

Instead create three **direction experiences**.

Use the existing examples:

SOFT FOCUS

AFTER DARK

WARM SURFACE

But present each as an olfactive world.
