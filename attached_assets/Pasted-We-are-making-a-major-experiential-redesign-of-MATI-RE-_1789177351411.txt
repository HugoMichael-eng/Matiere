We are making a major experiential redesign of MATIÈRE.

Do NOT rebuild the product architecture from scratch.

Preserve the underlying product logic, data, projects, materials, formulas and workflow.

However, visually and interactively, I want MATIÈRE to move significantly forward.

The current product is too dark, too static, too box-based and too conventional.

I want the redesign to create an immediate:

# “WHAT IS THIS? THIS IS BEAUTIFUL.”

reaction.

MATIÈRE should feel:

STUNNING  
CONTEMPORARY  
ARTISTIC  
EXPERIMENTAL  
INTELLIGENT  
TACTILE  
IMMERSIVE  
PRECISE  
CULTURAL  
FORWARD-LOOKING

It should not resemble generic SaaS.

It should not resemble traditional chemistry software.

It should not resemble a conventional fragrance database.

MATIÈRE should feel like a combination of:

a contemporary art gallery  
an architecture studio  
a fashion art-direction workspace  
a perfumer’s laboratory  
a visual research environment  
and an intelligent creative tool

The core concept is:

# FROM WORLD → TO SCENT

The user first builds a world.

MATIÈRE then helps translate that world into:

ATMOSPHERE  
OLFACTIVE LANGUAGE  
MATERIALS  
ACCORDS  
FORMULA  
MODS  
EVALUATION

This connection between visual culture and fragrance creation should become the defining identity of the product.

# 5. INFINITE / EXPANSIVE CANVAS FEEL

The Canvas should feel expansive.

Use a large warm-white working surface.

Allow the user to:

drag objects anywhere  
resize objects  
overlap objects  
group objects  
stack objects  
connect objects  
move clusters  
create negative space  
change visual hierarchy

Do not force everything into a grid.

Objects can intentionally break alignment.

The board should feel authored by the user.

# 7. IMAGES SHOULD FEEL PHYSICAL

Images are not thumbnails.

They are visual objects.

Allow:

very large images  
tiny references  
portrait crops  
wide landscape imagery  
full-bleed pieces  
overlap  
rotation only if extremely restrained  
free scaling

Images should sometimes occupy a large portion of the viewport.

Do not surround them with heavy cards.

---

# 8. IMAGE INTERACTIONS

When hovering an image:

- image slightly lifts
- subtle 1–2% scale
- very soft shadow / depth
- cursor indicates direct manipulation
- contextual actions quietly appear

Possible actions:

INTERPRET  
CONNECT  
NOTE  
STACK  
FOCUS  
•••

Controls should disappear when not needed.

Do not permanently place toolbars around every image.

---

# 9. DRAGGING SHOULD FEEL PHYSICAL

Dragging an object should feel tactile.

On pick-up:

object lifts slightly  
shadow increases  
background relationships become quieter

On drop:

object softly settles into place

If dragged onto another image:

show a subtle:

STACK →

or:

CONNECT →

drop target.

No playful bouncing.

No cartoon physics.

Motion should feel refined and architectural.

---

# 10. STACKING — SIGNATURE INTERACTION

Create a beautiful stacking interaction.

If the user overlaps multiple references, offer:

CREATE STACK

A stack may contain:

images  
text  
materials  
notes

When collapsed:

references overlap slightly like physical prints.

When selected:

the stack can subtly fan open.

Allow:

EXPAND STACK  
INTERPRET STACK  
UNSTACK

This should become one of MATIÈRE’s signature interactions.
